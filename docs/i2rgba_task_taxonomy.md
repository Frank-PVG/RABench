# I2RGBA Benchmark：完整单物体提取与外部干扰消除

日期：2026-10-02。状态：分类与评测设计，尚未制作新版数据。

**主任务：提取完整的单个物体，排除其他物体及其外部影响，并补全被遮挡的部分。**

在线文档中的原有多物体方案作为补充方向保留；本稿对应其中独立的单物体主任务分类。

旧 benchmarks/rgba_480 的物体类型分类数据已弃用。新版不通过给旧案例重新贴标签来构建。

## 1. 任务定义

输入：一张 RGB 场景图和明确的单物体目标指令。

输出：完整、可复用的单物体 RGBA 资产，保持目标身份、可见锚点的位置/尺度/朝向、固有结构和材质；去除其他物体及其造成的外部干扰，并恢复受遮挡或受污染的部分。

需要同时满足：

1. **保留目标本身**：形状、组成部件、固有颜色与纹理、文字、材质线索。
2. **排除非目标内容**：其他物体、原背景、支撑面，以及留在这些非目标表面上的投影/映像。
3. **消除进入目标的外部影响**：其他物体造成的遮挡、投影、接触暗部、串色、局部光色污染、可识别倒影，以及透过目标看到的旧背景内容。
4. **恢复完整性**：补全原先被遮挡的目标，结构合理且与可见部分一致；不能用缺块、擦除或全透明替代恢复。
5. **保持合成可用性**：边界和孔洞正确，透明度合理，换底后没有原场景内容残留。

这不是只给原 RGB 配一个 mask。其他物体的投影、串色和倒影若落在目标内部，复制 RGB 会把污染保留下来；被遮挡部分也没有可直接复制的源像素。

“一个物体”可以包含其自身组成部件，例如瓶身、瓶盖、标签，或人物自身的头发和衣服。杯子与杯垫、玩偶与外部覆盖纱不默认成为共同目标。输出范围必须在指令中明确，联合提取多个独立物体不作为本版主任务。

### 自身表现与外部污染的边界

| 来源/位置 | 处理要求 |
| --- | --- |
| 目标自身纹样、文字、几何凹凸、孔洞 | 保留 |
| 目标自身的形体明暗、自遮挡、自阴影及表现材质所需的基础高光 | 保留合理表现，避免抹平或改变材质 |
| 目标在其他物体/地面上留下的阴影或倒影 | 随非目标承接面排除 |
| 其他物体投射到目标上的阴影 | 清除外部投影，恢复受影响表面 |
| 邻物造成目标局部偏红、偏绿或异常发亮 | 去除指定外部污染，保持固有色和纹理 |
| 其他物体/场景文字在目标上的可识别倒影 | 清除外部映像，保持反射材质的合理外观 |
| 透过目标看到的旧背景 | 去除固定旧底成分，以 alpha 表达适合二维合成的透明度 |

应消除的是来自外部上下文的具体影响，不是把所有阴影和高光擦掉，也不是把所有物体涂成均匀纯色。统一白光重照明、去除全部环境照明或恢复纯反照率是更强的要求，不自动加入本任务。

## 2. 分类逻辑：干扰通过什么机制进入目标

主分类对应四个问题：

1. **归属错误**：哪些像素/组件属于目标，哪些属于外物？→ A。
2. **可见性损失**：目标的某些部分被外物直接遮住，需要恢复？→ B。
3. **像素混合**：细边、软边和透明介质把旧背景混进同一像素？→ C、D。
4. **表面外观污染**：几何表面仍属于目标，但它的 RGB 被外部阴影、光色或倒影改变？→ E、F、G。

这一区分决定了所需操作：选择/分离、补全、解混，以及外观恢复。物体类别是覆盖标签，不作为一级配额。

| 代码 | 主类别 | 核心任务 |
| --- | --- | --- |
| A | 目标归属与物体分离 | 选对单个目标，保留其组件，分开接触/相似干扰物 |
| B | 遮挡剥离与完整结构恢复 | 去掉遮挡物，并补全目标被遮住的部分 |
| C | 精细结构与边界解混 | 保留细丝和孔洞，恢复软边，去掉边界旧底污染 |
| D | 半透明解混与透过内容清除 | 清除透过介质看到的旧场景，同时保持介质与合理 alpha |
| E | 阴影与遮光影响消除 | 去掉外部投影/接触暗部，恢复受影响目标表面 |
| F | 串色与局部光色污染消除 | 去掉邻物或发光源造成的颜色污染，保持自身颜色和纹理 |
| G | 外部倒影与反射内容清除 | 去掉目标表面的外部映像，保持形状和反射材质感 |

本稿只定义分类，不设置 benchmark 总量或各类配额。实际样本数量由有效案例产出和可评测性决定；材料与物体类型作为横向覆盖属性，不决定主分类。

## 3. 各类子任务

### A. 目标归属与物体分离

- **A1 相似实例选择**：同类、同色、多实例中指定一个，关注选错对象或一并提取邻物。
- **A2 接触与粘连分离**：物体贴靠、边界低对比但没有关键结构缺失，关注沿接触处错误合并。
- **A3 组成部件与外部附件归属**：保留目标自身部件，去掉支架、夹具、外部包装；不因部件不连通而漏掉它。

例：只提取杯子，杯把要在，外部杯垫和支架要不在。杯把与支架同色相接时，应检查具体归属，不能只问“输出里有没有杯子”。

### B. 遮挡剥离与完整结构恢复

- **B1 局部实体遮挡**：外物遮住目标的一块区域，周边存在轮廓/纹理延续线索。
- **B2 分散遮挡**：网格、枝条或多个小物体遮住目标的多个不连续区域。
- **B3 交错、缠绕与包覆**：外部绳带等多次穿过目标前后，需要去掉外物并恢复多个被遮段。

本版按用户确认采用完整恢复：只提取已可见碎片不算完成。可见部分提取可作为基线输出分析，但不替代完整物体主任务。

需要同时检查：

- 原遮挡物是否清除。
- 目标是否完整，原遮挡区是否被恢复而非留成洞。
- 轮廓、连接关系、重复结构是否合理连续。
- 原可见部分的身份、结构和纹理是否保持。

补全会扩大相对于“原图可见部分”的目标范围，因此不能拿可见区域的包围框硬性限制完整目标尺寸；对齐应以可见锚点及其尺度/朝向为准。

无 GT 时，不可见的品牌字样、花纹和真实形状细节未必有唯一答案。只对输入或指令能支持的结构设严格答案；其余检查合理性，不声称恢复了隐藏真值。过度遮挡、几乎没有可识别线索的样本不进入严格事实判断子集。

### C. 精细结构与边界解混

- **C1 细丝和稀疏前景**：毛发、胡须、羽枝、细绳、枝梢等；去背景而不把细小目标一起删掉。
- **C2 孔洞与负空间**：把手、网格、蕾丝、字孔及凹口；孔内要透出新底，固有暗纹不能误挖成孔。
- **C3 软边和部分覆盖**：虚焦、运动模糊、亚像素边缘；恢复连续覆盖，消除白边、黑边和旧底色晕。

不透明物体也会有软 alpha。边缘混合导致的旧底颜色与 F 类的真实光照串色不同：C 主要处理覆盖率与混合像素，F 主要恢复已经被照明改变的目标表面。

### D. 半透明解混与透过内容清除

- **D1 单一透明介质**：薄纱、薄膜、烟雾等覆盖旧背景，需保留介质本身并清除透过它看到的旧纹理。
- **D2 透明与不透明部件混合**：透明瓶身＋不透明瓶盖/标签，或透明翼＋不透明身体；透明区解混，实体部件不变淡、不消失。
- **D3 非局部透过内容**：玻璃、磨砂和有色介质使旧背景发生变形、模糊或过滤；仍需清除原场景的可识别内容。

例：只提取盖在玩偶上的薄纱。玩偶本体及其透过纱看到的条纹都应去除；输出保留纱的褶皱、纤维、颜色、完整形状与透明度。

普通 RGBA 不能在任意新背景上自动计算正确折射、通道过滤或透射模糊。D3 的主标准是“旧内容清除＋材质与二维合成可用”，不要求普通 RGBA 在新底图上重新执行真实光路。[TOM-Net](https://guanyingc.github.io/TOM-Net/)、[Colored Transparent Object Matting](https://arxiv.org/abs/1910.02222)。

这项限制不取消透明物体提取，也不允许为保留旧折射图案而把旧场景烘焙进目标。

### E. 阴影与遮光影响消除

按作用方向区分：

- **E1 目标 → 外部承接面的投影**：例如杯子在桌上的投影，随桌面排除，不作为灰色浮块带出。
- **E2 其他物体 → 目标表面的投影**：例如枝条阴影落在杯身，需清除枝影并恢复杯身外观；仅抠掉桌面不能解决。
- **E3 外部接触/遮光暗部**：贴靠挡板或其他物体造成目标局部暗带，需要恢复，但保持目标自身凹槽和形体明暗。

例：移除白杯上的外部条纹投影。输出应无固定枝影，恢复处仍是连续、不透明且有曲面层次的杯身。挖成透明洞或涂成失去形体的平白块均不算成功。

本类须包含自身暗纹/自阴影对照，防止模型把目标原有黑条纹、凹槽或自身结构阴影一并擦掉。

### F. 串色与局部光色污染消除

- **F1 邻物漫反射串色**：红色物体靠近白杯，使杯身局部偏红。
- **F2 外部发光体/彩色反光污染**：邻近屏幕、彩灯或发光物使目标局部异常变色、变亮。
- **F3 多源污染与分区恢复**：同一目标不同区域受不同色源影响，去污染后仍保持一致材质和自然明暗。

主诊断同时看污染清除与自身保真。原本印在目标上的红色图案不能一起去掉。

优先选存在未污染区域、重复纹理或明确文本约束的样本。若整个物体被未知光色覆盖，单张 RGB 未必能确定原色；这类样本不能设置未经输入支持的唯一“真实 RGB”答案。

### G. 外部倒影与反射内容清除

- **G1 可识别物体倒影**：金属杯、光滑塑料等表面出现邻近人物或物体的映像。
- **G2 场景图案/文字反射**：窗格、屏幕字、招牌等反映到目标表面。
- **G3 变形/分散反射**：曲面、粗糙表面将外部映像扭曲或分散，需清除具体场景内容，同时恢复合理外观。

没有外部人物倒影不等于所有高光消失；把金属变成哑光塑料也不算成功。每条应标注需删除的具体映像，以及应保持的材质和形状证据。

没有隔离场景参考时，无法唯一确定新反射的全部像素。评测“外部内容清除＋合理材质保持”，不要求与未提供的隔离渲染逐像素一致。

## 4. 同一个物体怎样跨类出现

| 同一个白杯遇到的上下文 | 核心操作 | 主类 |
| --- | --- | --- |
| 与另一个白杯紧贴 | 判断边界，只选指定杯子 | A |
| 杯把被书遮住 | 去书并补全杯把 | B |
| 细杯把、孔边混入背景 | 保留边界与孔洞，去旧底色边 | C |
| 杯壁透明，透出条纹墙 | 去掉透过杯壁的旧条纹 | D |
| 杯身有外部枝条投影 | 清除投影并恢复杯身 | E |
| 红板让杯身一侧偏红 | 去串色但保留固有印花 | F |
| 镜面杯身反映出人物 | 去人物映像但保留材质感 | G |

不同机制可以外观相似。例如红条纹可能是固有印花、透过的背景、投影或倒影。制作时须提供足够线索或明确的任务指令，不能要求模型/评审从无法区分的 RGB 中猜测唯一因果解释。

## 5. 标签与归类规则

每条只有一个 primary_challenge，按主要诊断错误确定主分类；其他机制放入 secondary_challenges。

建议记录：

- target：唯一目标及组成部件。
- excluded_entities：需要去掉的外物、支撑物和直接背景。
- interaction_to_remove：作用源、受影响区域、污染形式。
- intrinsic_features_to_preserve：固有图案、文字、结构、自身明暗与材质线索。
- completion_regions：需要补全的遮挡区域，以及可见结构依据。
- uncertain_features：不能由输入唯一确定的隐藏细节，不设伪造真值。
- evidence_regions：污染区、未污染参考区、细结构区、可见对齐锚点。
- scene_group_id：同一目标/场景的条件变体关联。
- coverage_tags：物体类型、材料、干扰强弱、遮挡面积、背景对比、目标大小等。

复杂场景可以同时有 B/E/F 等标签，但不因多个标签重复计数。主分类必须与本条核心问题对应，不能只因为画面中出现某个元素就自动归类。

## 6. 无 GT 的问题与标准答案

核心题覆盖三方面：

1. 外部干扰是否真正消失。
2. 目标自身身份、结构、纹理和材质是否保持。
3. 补全/恢复是否引入缺块、透明洞、涂抹或明显结构错误。

| 输入与任务 | 诊断问题 | 标准答案 |
| --- | --- | --- |
| 只提取白杯，桌面有杯子投影 | 桌面投影是否作为灰块留在目标外？ | 否 |
| 白杯受外部枝条投影 | 枝条投影是否仍可辨？恢复区域是否仍不透明且有合理曲面明暗？ | 否；是 |
| 白杯被红板局部串色，未污染区域提供颜色依据 | 原污染区是否仍异常偏红？固有红色印花是否保留？ | 否；是 |
| 金属壶映出旁边人物 | 人物倒影是否仍可辨？壶是否仍具有合理金属反光质感？ | 否；是 |
| 只提取覆盖条纹玩偶的薄纱 | 玩偶条纹是否固定在纱图层里？纱自身结构和透底是否保留？ | 否；是 |
| 杯把中段被书挡住，要求完整杯子 | 书是否已移除？杯把是否形成合理连续结构？原可见段是否保持？ | 是；是；是 |

每个答案须有输入图、指令或明确任务约定支持。隐藏区的精确花纹、未知反照率、无污染时精确光照不得凭空指定唯一真值。

公共文件/画布检查与难点诊断分开统计；不能用大量重复“是否透明”的问题替代不同恢复机制的覆盖。

### 观察与判分

- 源 RGB 与局部区域：确定要去掉的污染、应保持的自身特征，以及补全线索。
- 黑/白/灰/图案底预览：检查残留、孔洞、连续 alpha，及是否把污染区误挖成洞。
- 可控的输入对照：同一目标更换遮挡物、色源或反射环境；去干扰后的结果应保留同一物体的身份和材质。无需把这些对照当作 GT RGBA。
- VLM 返回实际可见证据；证据不足时进入复核。
- 分别报告干扰清除、目标保真、恢复完整性及整体成功率。只报干扰消失率会奖励擦除或涂平目标。
- 不以源图被污染区域的 RGB 完全一致作为保真目标；那会反而惩罚正确去污染。
- 不报告没有参考依据的像素 GT 误差、真实反照率误差或精确光学准确率。

“补全合理”和“恢复了隐藏真实外观”不同；无 GT 且输入不足时只能支持前一种结论。

## 7. 后续构建原则

- 本分类聚焦完整单物体 I2RGBA；多物体联合提取与组内影响保留作为补充方向，单独适用。
- 每类包含明显干扰、弱/无干扰对照，以及与自身纹样/阴影/高光容易混淆的保真对照。
- 同场景变体按 scene_group_id 关联，不能视为相互独立的场景；换底预览不计为新条目。
- 材料和物体类型横向覆盖，防止“串色类只有白杯”“遮挡类只有人物”等捷径。
- I2RGBA 输入可以先写制作描述，但阴影、色偏、倒影、遮挡等预期必须与最终 RGB 核对后才能作为正式标准答案。
- 本稿记录分类与任务边界，尚未重新编写或生成新版案例；不预设各类数量。
